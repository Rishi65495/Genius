Leafline for Android & Mobile

Install directly to your home screen for offline PDF reading, instant launch, and full-screen experience.

Build an Android APK:
1. Open PWABuilder.com
2. Enter your server URL (e.g. http://your-server:3000)
3. Click "Generate" → "Android" → Download APK
4. Enable "Install from unknown sources" on your Android device
5. Transfer and install the .apk file
Manual home screen install (Chrome on Android):
1. Open http://your-server:3000 in Chrome
2. Tap the three-dot menu (⋮)
3. Tap "Add to Home screen"
4. Tap "Add" — Done! App icon appears on home screen
